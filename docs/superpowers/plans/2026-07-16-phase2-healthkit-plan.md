# Jarvi Phase 2 HealthKit Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pull calories-burned data from Apple Health into Jarvi so Today's log shows a real intake-vs-burned balance.

**Architecture:** A new `app/src/health/healthKit.ts` module wraps `@kingstinct/react-native-healthkit` for permission requests and a same-day active+resting energy sum; `DailyViewScreen` calls it alongside the existing SQLite fetch and adds a burned/balance line to the totals header, with graceful degradation if permission is denied or the platform isn't iOS.

**Tech Stack:** `@kingstinct/react-native-healthkit` (+ its Expo config plugin), `npx expo prebuild`, Xcode (free Apple ID / personal-team signing).

## Global Constraints

- iOS only — HealthKit has no Android equivalent in this app; Android must render Today's log exactly as it does today (no burned/balance line, no crash).
- Calories burned = active energy + resting/basal energy, summed for the same **local calendar day** `todayKey()` already uses (Phase 1 fixed a UTC-vs-local mismatch bug between meal-tagging and date-bucketing — this feature must use local-day boundaries, not UTC, or it reintroduces that same bug class).
- Permission denial must never block or nag — Today's log still shows intake totals normally; only the burned/balance line is replaced with a tappable "Connect Health" retry.
- No paid Apple Developer account — build via Xcode with a free Apple ID (personal team).
- This is the first Jarvi feature requiring a native dev-client build; Expo Go can no longer run the app after this point.

- [ ] **Step 3: Implement healthKit.ts**

This reference implementation targets `@kingstinct/react-native-healthkit`'s commonly-documented API shape. If Task 1 Step 4 found different actual export names in the installed version, adapt the imports and calls below to match — keep the two exported function signatures (`requestHealthPermissions`, `getCaloriesBurned`) and the `getLocalDayBounds` helper identical, since Task 3 depends on those exact names.

```ts
import { Platform } from 'react-native';
import {
  isHealthDataAvailableAsync,
  requestAuthorization,
  queryStatisticsForQuantity,
  HKQuantityTypeIdentifier,
  HKStatisticsOptions,
} from '@kingstinct/react-native-healthkit';

export function getLocalDayBounds(date: Date): { start: Date; end: Date } {
  const start = new Date(date.getFullYear(), date.getMonth(), date.getDate(), 0, 0, 0, 0);
  const end = new Date(date.getFullYear(), date.getMonth(), date.getDate() + 1, 0, 0, 0, 0);
  return { start, end };
}

export async function requestHealthPermissions(): Promise<boolean> {
  if (Platform.OS !== 'ios') {
    return false;
  }
  const available = await isHealthDataAvailableAsync();
  if (!available) {
    return false;
  }
  try {
    await requestAuthorization(
      [],
      [HKQuantityTypeIdentifier.activeEnergyBurned, HKQuantityTypeIdentifier.basalEnergyBurned]
    );
    return true;
  } catch {
    return false;
  }
}

async function sumQuantity(identifier: HKQuantityTypeIdentifier, start: Date, end: Date): Promise<number> {
  const stats = await queryStatisticsForQuantity(identifier, {
    from: start,
    to: end,
    options: [HKStatisticsOptions.cumulativeSum],
  });
  return stats?.sumQuantity?.quantity ?? 0;
}

export async function getCaloriesBurned(date: Date): Promise<number> {
  if (Platform.OS !== 'ios') {
    return 0;
  }
  const { start, end } = getLocalDayBounds(date);
  const [active, resting] = await Promise.all([
    sumQuantity(HKQuantityTypeIdentifier.activeEnergyBurned, start, end),
    sumQuantity(HKQuantityTypeIdentifier.basalEnergyBurned, start, end),
  ]);
  return active + resting;
}
```

Replace the full contents of `app/src/screens/DailyViewScreen.tsx`:

```tsx
import { useCallback, useEffect, useState } from 'react';
import { Platform, Pressable, ScrollView, StyleSheet, Text } from 'react-native';
import MealSection from '../components/MealSection';
import { getEntriesForDate, StoredEntry, updateMealType } from '../db/entriesRepository';
import { aggregateDailyTotals } from '../nutrition/aggregation';
import { getCaloriesBurned, requestHealthPermissions } from '../health/healthKit';
import { MealType, NutrientProfile } from '../types/nutrition';

const MEAL_ORDER: MealType[] = ['breakfast', 'lunch', 'dinner', 'snack'];

function todayKey(): string {
  const d = new Date();
  const y = d.getFullYear();
  const m = String(d.getMonth() + 1).padStart(2, '0');
  const day = String(d.getDate()).padStart(2, '0');
  return `${y}-${m}-${day}`;
}

export default function DailyViewScreen() {
  const [entries, setEntries] = useState<StoredEntry[]>([]);
  const [caloriesBurned, setCaloriesBurned] = useState<number | null>(null);
  const [healthConnected, setHealthConnected] = useState(false);

  const refetch = useCallback(() => {
    getEntriesForDate(todayKey()).then(setEntries);
  }, []);

  const connectHealth = useCallback(async () => {
    const granted = await requestHealthPermissions();
    setHealthConnected(granted);
    if (granted) {
      const burned = await getCaloriesBurned(new Date());
      setCaloriesBurned(burned);
    }
  }, []);

  useEffect(() => {
    refetch();
  }, [refetch]);

  useEffect(() => {
    if (Platform.OS === 'ios') {
      connectHealth();
    }
  }, [connectHealth]);

  async function handleMealTypeChange(entryId: number, nextMealType: MealType) {
    await updateMealType(entryId, nextMealType);
    refetch();
  }

  const allItemNutrients: NutrientProfile[] = entries.flatMap((e) => e.items.map((i) => i.nutrients));
  const totals = aggregateDailyTotals(allItemNutrients);

  return (
    <ScrollView contentContainerStyle={styles.container}>
      <Text style={styles.totalsHeading}>Today's totals</Text>
      <Text style={styles.totalsLine}>{Math.round(totals.calories)} cal · {Math.round(totals.proteinG)}g protein · {Math.round(totals.carbsG)}g carbs · {Math.round(totals.fatG)}g fat</Text>
      {Platform.OS === 'ios' && (
        healthConnected && caloriesBurned !== null ? (
          <Text style={styles.balanceLine}>
            {Math.round(totals.calories)} cal in · {Math.round(caloriesBurned)} cal out · {Math.round(totals.calories - caloriesBurned) >= 0 ? '+' : ''}{Math.round(totals.calories - caloriesBurned)} net
          </Text>
        ) : (
          <Pressable onPress={connectHealth}>
            <Text style={styles.connectHealthLine}>Connect Health to see today's balance</Text>
          </Pressable>
        )
      )}
      {MEAL_ORDER.map((mealType) => (
        <MealSection
          key={mealType}
          mealType={mealType}
          entries={entries.filter((e) => e.mealType === mealType)}
          onMealTypeChange={handleMealTypeChange}
        />
      ))}
    </ScrollView>
  );
}

const styles = StyleSheet.create({
  container: { padding: 16 },
  totalsHeading: { fontSize: 18, fontWeight: '700', marginBottom: 4 },
  totalsLine: { color: '#444', marginBottom: 4 },
  balanceLine: { color: '#444', marginBottom: 16 },
  connectHealthLine: { color: '#185FA5', marginBottom: 16 },
});
```
