# Tour photos

The photos in this folder are free stock photos from Pexels, used in the first-run tour
(`src/screens/TutorialScreen.tsx`). The Pexels licence allows free use and changes without
credit; the source pages are kept here so each file can be traced. Each was cropped to the
tour's 4:5 picture and shrunk to 724 x 904 (the `-sq` files are 320 x 320 square crops).

| File | Source page |
|---|---|
| `move.jpg`, `move-sq.jpg` | https://www.pexels.com/photo/man-running-on-street-at-sunset-17693987/ |
| `food.jpg`, `food-sq.jpg` | https://www.pexels.com/photo/woman-taking-photo-of-meal-on-plate-with-smartphone-17322370/ |
| `scale.jpg` | https://www.pexels.com/photo/a-person-wearing-gray-socks-standing-on-a-weighing-scale-7991906/ |

The people shown have no connection to BiteLog and do not endorse it. Chosen by Pranav on
2026-11-13. A watch photo (Pexels 20657581) was picked first and then dropped, because it made
the app look as if it needed a smart watch.
